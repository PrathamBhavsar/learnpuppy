# LearnPuppy

Local learning web app: a visual learning harness, a cross-session Knowledge Graph, and FSRS spaced repetition, with multiple isolated workspaces.

`learnpuppy serve` runs a Rust (axum) server on `127.0.0.1` and serves a Vite + React + shadcn SPA that is embedded in the binary. Nothing leaves your machine except the calls your own `claude`, `codex` and `agy` CLIs make.

## Requirements
- macOS or Linux, with [Rust](https://rustup.rs) and [bun](https://bun.sh) to build.
- At least one logged-in agent CLI: `claude`, `codex` or `agy`. Several Claude profiles (`~/.claude`, `~/.claude-accounts/*`) are used as separate rate-limit buckets and failed over automatically.

## Install
```sh
make release          # builds the SPA, then target/release/learnpuppy (one self-contained binary)
make install          # or: build and `cargo install` it onto your PATH
```

## Use
```sh
learnpuppy doctor     # checks the data dir, port, disk and which CLI logins were found
learnpuppy serve      # prints a one-time launch URL; open it (a second `serve` reuses the running one)
learnpuppy migrate    # one-time: move an old single-store ~/.learnpuppy into a "Default" workspace (`--revert` undoes it)
```
Data lives in `~/.learnpuppy` (override with `LEARNPUPPY_HOME`). The server binds `127.0.0.1` only, trades the launch token for an `HttpOnly` cookie, and rejects foreign `Host`/`Origin`.

## Develop
```sh
export PATH=/opt/homebrew/opt/rustup/bin:$PATH
cargo run -p lp-server -- serve --dev   # faux engine, no launch token
make gate                               # fmt, clippy, tests, OKF, OpenAPI drift
make e2e                                # Playwright: mock-mode suites + serve-mode suites against the real server
make perf                               # budgets; LP_SOAK_MIN=30 for the soak (see web/e2e/perf)
```
`web/openapi/openapi.json` is generated by the server; `web/src/api/schema.d.ts` is generated from it (`bun run gen:api`). The client is typed against that contract, so a server change that the UI does not follow fails `tsc`.

## Known limits
- agy was out of quota when this was verified (resets about 50 h later), so agy as the teacher and its token counts are untested; failover away from it is tested.
- The graph legend's claim/concept/procedure/decision kinds are cosmetic: the wire has only the source kind.
- Verified on real CLIs: Probe/Plan/Teach, Practice, workbench jobs (research, visual, PDF), ingest and Digest. `/review-all` was only checked against the scripted engine and mocks.
