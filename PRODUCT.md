# Product

## Register
brand

## Users
Self-directed learners and developers who study with AI CLIs (`claude`, `codex`, `agy`) and want what they learn to stick. They arrive from GitHub or a recommendation, on a laptop, wanting proof it is real, local and private before they install.

## Product Purpose
LearnPuppy is a local web app: an AI tutor that probes, plans and teaches, a cross-session Knowledge Graph, and FSRS spaced repetition, with isolated workspaces. A Rust server on 127.0.0.1 with the web app embedded in one binary, driving the agent CLIs the user already has. Pre-release, repo currently private: build from source works today, release downloads once public.

## Brand Personality
Warm, exact, a little playful. A pixel pup and a hot pink accent, but the copy stays plain and specific. Confident through mechanisms, not adjectives.

## Anti-references
Generic SaaS gradients, glassmorphism, stock "learning" imagery (brains, lightbulbs), fake logos, invented user counts or retention claims, hero-metric tiles, icon-card grids.

## Design Principles
1. Show the mechanism: a graph that lights up as it is used, and a forgetting curve that jumps back at each review. The curve is labelled a synthetic illustration, never a result.
2. Real facts only: bind address, data folder, which CLIs it drives, known limits. No benchmarks, no user numbers.
3. Say plainly what works today: the Source install tab comes first; the Binary tab says it needs a public repo.
4. Dark only. One saturated field per page (the install band) carries the pink at scale.

## Accessibility & Inclusion
WCAG AA contrast, visible focus, keyboard-operable tabs and docs nav, `prefers-reduced-motion` freezes the ASCII canvas on a complete still frame, canvas is aria-hidden with all copy in real text.

## Brand commitments
Fonts: Geist Pixel Square (display), Satoshi (body), Geist Mono (code). Icons: Hugeicons. Dark theme only. ASCII canvas hero background. Accent #FF6AD5 on ink #09080d.
