# Releasing

Tag push `vX.Y.Z` -> GitHub Actions `.github/workflows/release.yml` (generated by cargo-dist) builds and publishes a GitHub Release.

## Cut a release

1. Bump `[workspace.package] version` in `Cargo.toml` (tag must match), `cargo check` to refresh `Cargo.lock`.
2. Merge to `prod` via the usual flow, run the local final gate.
3. `git tag vX.Y.Z && git push origin vX.Y.Z`.
4. Workflow: `plan` -> `build-local-artifacts` (4 targets) -> `build-global-artifacts` (installer, checksums) -> `host` -> `announce`.

Each build job first runs `.github/workflows/build-setup.yml`: setup bun, `bun install --frozen-lockfile && bun run build` in `web/`, `touch crates/lp-server/src/assets.rs` so rust-embed re-embeds `web/dist`. `web/dist` is not committed.

## Assets

Targets: `aarch64-apple-darwin`, `x86_64-apple-darwin`, `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu`.

- `lp-server-<target>.tar.xz` (contains `learnpuppy`) plus `.sha256` each
- `lp-server-installer.sh`
- `sha256.sum`, `source.tar.gz`, `source.tar.gz.sha256`, `dist-manifest.json`

## Install

```sh
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/PrathamBhavsar/learnpuppy/releases/latest/download/lp-server-installer.sh | sh
learnpuppy doctor && learnpuppy serve
```

Installs to `$CARGO_HOME/bin` (`~/.cargo/bin`).

Repo is private for now: the curl one-liner only works once the repo is public. Until then, authenticated users:

```sh
gh release download --repo PrathamBhavsar/learnpuppy --pattern 'lp-server-installer.sh' -O - | sh
```

(or download the tarball for your target and put `learnpuppy` on `PATH`).

## Regenerate workflow

After editing `dist-workspace.toml` or `.github/workflows/build-setup.yml`: `dist generate` then `dist plan`. Never hand-edit `release.yml`.
